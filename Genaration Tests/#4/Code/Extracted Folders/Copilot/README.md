
# Modern Weather App

## Structure
- backend.py : FastAPI backend for Open-Meteo communication
- main.py : Fullscreen CustomTKInter desktop GUI
- requirements.txt : Dependencies

## Features
- City search using Open-Meteo geocoding
- FastAPI backend
- Fullscreen GUI
- Theme switching
- Matplotlib forecast chart
- Current weather metrics

## Run
pip install -r requirements.txt
python main.py
